# RAG-Applications

> 🚧 **Work in progress!** This repo is actively growing — it's not a finished reference yet, so expect notebooks to change, get reorganized, or get rewritten as new ideas land.

A hands-on, notebook-by-notebook build-up of Retrieval-Augmented Generation, going from first-principles fundamentals to a full evaluated pipeline:

1. **Text Summarization**
2. **Web Research Engine**
3. **RAG Fundamentals**
4. **LangChain RAG**
5. **Indexing** — chunking strategies (granular vs. coarse)
6. **Semantic Search** — keyword, semantic, and hybrid retrieval
7. **Encoder-Decoder Models** — a full pipeline with chunking, embeddings, vector search, generation, and component-level evaluation (retrieval, generation, held-out testing)

## What's coming next 🔥

This is just the foundation — the exciting part is what's next:

- **Self-corrective RAG** — retrieval that checks itself and recovers from bad context instead of confidently answering from garbage
- **Reasoning-augmented RAG** — combining retrieval with multi-step reasoning for harder, multi-hop questions
- More real-world examples and datasets as the collection grows

More notebooks, more techniques, and sharper evaluation are on the way — stay tuned!
